*TWO REAL BUGS the new tests caught*

1. open_app accepted ANY well-formed package name.
   InputGuards.packageRef matched PACKAGE_REGEX, so "open com.evil.backdoor"
   passed validation, execute() returned the raw string, and the UI reported
   "Opening." — the exact opposite of the documented allowlist. The guard claimed
   to be an allowlist but was only a syntax check.
   Fixed: allowlist membership only. Regression test added.

2. get_today never ran at all.
   ToolRegistry cast every tool to DotTool<Map<String,String?>, _>, so the
   DotTool<Unit, _> tool received an empty map and threw ClassCastException on
   the synthetic bridge — surfacing as tool_error, not as the tool executing.
   Latent since the original commit; only appeared once something actually
   invoked the registry.
   Fixed: added the UnitInputTool marker so the registry dispatches on the real
   input type. Regression test added.
